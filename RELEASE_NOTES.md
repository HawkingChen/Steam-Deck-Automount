# v0.1.0 (Preview)

Keeps the automatic mounting setup across normal SteamOS updates using the system update keep-list. Includes one-command setup, an English status/menu, selectable internal partitions by UUID, and detected local user. Supports USB drives and SD cards in Gaming Mode and Desktop Mode.

Based on scawp/Steam-Deck.Mount-External-Drive under its original DBAD Public License 1.2.

Validation: Python setup/removal simulations, shell syntax checks, and udev rule validation. Cross-device reboot/hotplug and an actual SteamOS upgrade have not yet been validated. Use this preview to test on your own machine.
